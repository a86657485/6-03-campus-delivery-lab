# 角色素材生成说明

本项目使用内置图像生成工具生成两张透明背景角色立绘。当前工具没有返回可核验的具体模型版本，因此项目不把素材标注为经验证的“image2.5”输出。

## 岚老师

文件：`assets/teacher-lan.png`

生成提示要点：中国小学阅读室管理员，32岁左右，友善、专业、沉着，手持数字调度平板，另一只手作引导手势；半写实2D教育游戏风格，鼠尾草绿开衫、奶油色衬衫、深蓝下装；透明背景，无文字、无标志、无水印。

## 小达机器人

文件：`assets/robot-xiaoda.png`

生成提示要点：校园配送机器人，白色与淡鼠尾草绿圆角机身，四个小轮、图书储物仓、暖黄状态灯，友好但不过度拟人的LED表情；半写实2D教育游戏风格，透明背景，无文字、无标志、无水印。

两张素材均为1024×1536 PNG，已核对保留 alpha 透明通道。剧情中的中文、姓名、倒计时、对话和状态均由网页绘制。

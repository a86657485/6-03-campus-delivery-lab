# 校园配送实验室课程扩展实施计划

**目标：**在原有故事和二维仿真中加入可执行指令实验、每次 20 题的独立考核，以及考核后的完整送书机器人设计作品；维持真实课堂数据和教师测试模式。

**依据：**教材第19—22页的学习目标、手动推车任务表、机器人设计表与参数拓展；用户已确认的40分钟、一人一机、无实物和流畅动画要求。

**技术：**沿用原生网页、共享规则模块、Node SQLite课堂服务。旧记录通过兼容验证保留，新任务只有完成实际操作或提交后才得积分。

- [ ] 编写并验证两个20题情境考核卷、答题与首答/最近成绩模型。
- [ ] 实现逐条指令编辑、逐步运行、故障定位与修订记录。
- [ ] 在考核后增加教材完整机器人设计表，功能选择或输入触发三次组装升级。
- [ ] 接入故事、关卡解锁、教师大屏和教师测试模式。
- [ ] 使用隔离数据走通错误—调试—成功—考核—设计—保存流程；检查旧记录兼容和动画减弱设置。
- [ ] 更新课堂说明，提交并推送GitHub，验证本地IP入口。

活动时长以设计预估标注。前四个动手环节合计安排25分钟以上；20题考核和设计作品不靠倒计时延长。
